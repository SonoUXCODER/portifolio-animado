Sandra Hair Salon

Brand Site / Multilingual / 2025

A salon in Buchs (SG) serves German, English and Portuguese across the same counter. The site had to do exactly that, without turning into three sites maintained by one person who does not write code.

↳this is where I stopped treating translation as a layer and started treating it as architecture.

The challenge

What wasbroken.

The neighbourhood is trilingual. Translating afterwards, as a layer on top, always breaks something: a price renders wrong, a button overflows, someone lands on half a page in German. And the salon needed to change its own prices without opening a code editor.

The approach

How itwas made.

  1. Research

    Which language actually walks in

    Three days of counter observation, not analytics. German for appointments, Portuguese for the long conversations, English for everyone passing through. That order became the order of the language switch.

  2. UX Strategy

    One page, three readings

    Language is state, not a route. Switching happens in place, keeps the scroll position, and rewrites currency, opening hours and date format along with the words.

  3. Wireframes

    The price table is the page

    Everything else supports it. Service, duration, price in CHF, and a booking button attached to each row, because the question a salon site has to answer is always “how much, how long”.

  4. UI Design

    Gold on espresso

    The salon’s own interior is dark wood and warm brass, so the site is too. Type is generous, contrast is high, and the tap targets are sized for a wet-handed thumb in a mirror-lit room.

  5. Development

    One dictionary, no build step

    Every string lives in a single dictionary keyed by language. The service table reads a plain data file the salon edits directly; the booking button composes a pre-written WhatsApp message in the language currently selected.
